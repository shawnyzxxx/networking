# HCIP 第一次作业：VLAN 与混合接口组网实验

## 文章导读
本篇是 HCIP 第一次作业，通过**Access、Hybrid、Trunk 三种接口类型**配合 VLAN 划分，实现多 PC 之间的差异化访问控制，并配合**单臂路由与 DHCP** 完成跨网段通信。适合学习华为交换机高级 VLAN 配置的读者。

## 一、实验要求
1. PC1 和 PC3 所在接口为 access 接口，属于 **VLAN 2**
2. PC2/4/5/6 处于同一网段，其中：
   - PC2 可以访问 PC4/5/6
   - PC4 可以访问 PC5，不能访问 PC6
   - PC5 不能访问 PC6
3. PC1/3 和 PC2/4/5/6 不在一个网段，且可以正常通讯
4. 所有 PC 通过 DHCP 获取 IP 地址，且 PC1/3 可以正常访问 PC2/4/5/6

## 二、实验过程

### 1. 配置交换机 SW1
```
[sw1]vlan batch 2 to 6

[sw1]int g0/0/3
[sw1-GigabitEthernet0/0/3]port link-type access
[sw1-GigabitEthernet0/0/3]port default vlan 2

[sw1]int g0/0/4
[sw1-GigabitEthernet0/0/4]port link-type hybrid
[sw1-GigabitEthernet0/0/4]port hybrid pvid vlan 3
[sw1-GigabitEthernet0/0/4]port hybrid untagged vlan 2 to 6

[sw1]int g0/0/2
[sw1-GigabitEthernet0/0/2]port link-type trunk
[sw1-GigabitEthernet0/0/2]port trunk allow-pass vlan 2 to 6

[sw1]int g0/0/1
[sw1-GigabitEthernet0/0/1]port link-type hybrid
[sw1-GigabitEthernet0/0/1]port hybrid untagged vlan 3 to 6
[sw1-GigabitEthernet0/0/1]port hybrid tagged vlan 2
```

### 2. 配置交换机 SW2
```
[sw2]vlan batch 2 3 4 5 6

[sw2]int g0/0/3
[sw2-GigabitEthernet0/0/3]port link-type access
[sw2-GigabitEthernet0/0/3]port default vlan 2

[sw2]int g0/0/4
[sw2-GigabitEthernet0/0/4]port link-type hybrid
[sw2-GigabitEthernet0/0/4]port hybrid pvid vlan 4
[sw2-GigabitEthernet0/0/4]port hybrid untagged vlan 2 3 4 5

[sw2]interface GigabitEthernet 0/0/1
[sw2-GigabitEthernet0/0/1]port link-type trunk
[sw2-GigabitEthernet0/0/1]port trunk allow-pass vlan 2 3 4 5 6

[sw2]interface GigabitEthernet 0/0/2
[sw2-GigabitEthernet0/0/2]port link-type trunk
[sw2-GigabitEthernet0/0/2]port trunk allow-pass vlan 2 3 4 5 6
```

### 3. 配置交换机 SW3
```
[sw3]vlan batch 2 3 4 5 6

[sw3]interface GigabitEthernet 0/0/2
[sw3-GigabitEthernet0/0/2]port link-type hybrid
[sw3-GigabitEthernet0/0/2]port hybrid pvid vlan 5
[sw3-GigabitEthernet0/0/2]port hybrid untagged vlan 2 3 4 5

[sw3]interface GigabitEthernet 0/0/3
[sw3-GigabitEthernet0/0/3]port link-type hybrid
[sw3-GigabitEthernet0/0/3]port hybrid pvid vlan 6
[sw3-GigabitEthernet0/0/3]port hybrid untagged vlan 2 3 6

[sw3]interface GigabitEthernet 0/0/1
[sw3-GigabitEthernet0/0/1]port link-type trunk
[sw3-GigabitEthernet0/0/1]port trunk allow-pass vlan 2 3 4 5 6
```

### 4. 配置路由器 AR1（单臂路由 + DHCP）
```
[AR1]interface GigabitEthernet 0/0/0
[AR1-GigabitEthernet0/0/0]ip address 192.168.1.1 255.255.255.0

[AR1]interface GigabitEthernet 0/0/0.2
[AR1-GigabitEthernet0/0/0.2]ip address 192.168.2.1 255.255.255.0
[AR1-GigabitEthernet0/0/0.2]dot1q termination vid 2
[AR1-GigabitEthernet0/0/0.2]arp broadcast enable

[AR1]dhcp enable
[AR1]ip pool pool1
[AR1-ip-pool-pool1]network 192.168.1.0 mask 255.255.255.0
[AR1-ip-pool-pool1]gateway-list 192.168.1.1
[AR1-ip-pool-pool1]dns-list 8.8.8.8

[AR1]ip pool pool2
[AR1-ip-pool-pool2]network 192.168.2.0 mask 255.255.255.0
[AR1-ip-pool-pool2]gateway-list 192.168.2.1
[AR1-ip-pool-pool2]dns-list 8.8.8.8

[AR1]interface GigabitEthernet 0/0/0
[AR1-GigabitEthernet0/0/0]dhcp select global
[AR1]interface GigabitEthernet 0/0/0.2
[AR1-GigabitEthernet0/0/0.2]dhcp select global
```
> 说明：原稿中最后一个接口 `dhcp select global` 误写为 `GigabitEthernet 0/0/1.2`，应为 `0/0/0.2`，上文已修正。

## 三、实验实现与结果
按上述配置后，验证各 PC 的访问关系：

- PC2 访问 PC4、PC5、PC6：通过
- PC4 可以访问 PC5，不能访问 PC6：符合要求
- PC5 不能访问 PC6：符合要求

## 四、实验结果
实验成功，各 PC 的访问控制与跨网段通信均符合题目要求。
