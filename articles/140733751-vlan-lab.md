# VLAN 配置实验报告

## 文章导读
本篇是华为设备 VLAN 配置的综合实验报告，通过**创建 VLAN、划分交换机接口、配置干道（Trunk）、单臂路由跨 VLAN 转发、DHCP 动态分配 IP**，实现多 VLAN 网络的全网可达。适合学习 Huawei 交换机与路由器 VLAN 配置的读者。

## 一、实验需求
1. PC1、PC3 属于 **VLAN 2**
2. PC2、PC4 属于 **VLAN 3**
3. 通过 DHCP 使 PC 自动获取 IP 地址信息
4. 全网可达

## 二、需求分析
1. 创建 VLAN
2. 将交换机接口划入相应 VLAN
3. 配置干道（Trunk）
4. 路由器划分子接口（单臂路由）
5. DHCP 动态分配 IP

## 三、实验步骤

### 1. 创建 VLAN 并划分交换机接口

```
// 将交换机 LSW1 的 g0/0/2 接口划入 vlan2
[LSW1]vlan batch 2 to 3
[LSW1]int g0/0/2
[LSW1-GigabitEthernet0/0/2]port link-type access
[LSW1-GigabitEthernet0/0/2]port default vlan 2

// 将交换机 LSW1 的 g0/0/3 接口划入 vlan3
[LSW1]int g0/0/3
[LSW1-GigabitEthernet0/0/3]port link-type access
[LSW1-GigabitEthernet0/0/3]port default vlan 3

// 将交换机 LSW2 的 g0/0/2 接口划入 vlan2
[LSW2-GigabitEthernet0/0/2]port link-type access
[LSW2-GigabitEthernet0/0/2]port default vlan 2

// 将交换机 LSW2 的 g0/0/3 接口划入 vlan3
[LSW2-GigabitEthernet0/0/3]port link-type access
[LSW2-GigabitEthernet0/0/3]port default vlan 3
```
> 原稿中部分命令的接口号书写有误（如 g0/0/3 处误写为 g0/0/2），上文已按逻辑修正。

### 2. 配置干道（Trunk）

```
[LSW1-GigabitEthernet0/0/4]port link-type trunk
[LSW1-GigabitEthernet0/0/4]port trunk allow-pass vlan 2 to 3

[LSW2-GigabitEthernet0/0/1]port link-type trunk
[LSW2-GigabitEthernet0/0/1]port trunk allow-pass vlan 2 to 3
```

### 3. 单臂路由：路由器划分子接口转发
通过在路由器上划分子接口，为不同 VLAN 提供网关，实现跨 VLAN 转发。

```
// 先创建子接口 g0/0/0.2 和 g0/0/0.3，分配对应 VLAN，并开启 ARP 应答
[SW1-GigabitEthernet0/0/1]port link-type trunk
[SW1-GigabitEthernet0/0/1]port trunk allow-pass vlan 2 3

[R1]int g0/0/0.2
[R1-GigabitEthernet0/0/0.2]ip add 192.168.1.254 24
[R1-GigabitEthernet0/0/0.2]dot1q termination vid 2
[R1-GigabitEthernet0/0/0.2]arp broadcast enable

[R1]int g0/0/0.3
[R1-GigabitEthernet0/0/0.3]ip add 192.168.2.254 24
[R1-GigabitEthernet0/0/0.3]dot1q termination vid 3
[R1-GigabitEthernet0/0/0.3]arp broadcast enable
```
> `dot1q termination vid` 用于把子接口与指定 VLAN 绑定，`arp broadcast enable` 开启 ARP 广播应答。

### 4. 配置 DHCP 动态分配 IP

```
[R1]ip pool v2
Info: It's successful to create an IP address pool.
[R1-ip-pool-v2]network 192.168.1.0 mask 24
[R1-ip-pool-v2]gateway-list 192.168.1.254
[R1]int g0/0/0.2
[R1-GigabitEthernet0/0/0.2]dhcp select global

[R1]ip pool v3
[R1-ip-pool-v3]network 192.168.2.0 mask 24
[R1-ip-pool-v3]gateway-list 192.168.2.254
[R1]int g0/0/0.3
[R1-GigabitEthernet0/0/0.3]dhcp select global
```

## 四、实验验证

**1. 查看 PC 获取的 IP**
在 PC 端命令行输入 `ipconfig` 查看 IP 地址。

**2. 测试全网可达**
以 PC1 为例，分别与 PC2、PC3、PC4 互通，验证跨 VLAN 通信是否正常。

## 五、实验结论
成功完成 VLAN 划分、干道配置、单臂路由与 DHCP 配置，各 PC 正确获取 IP，全网可达。
