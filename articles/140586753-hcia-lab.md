# HCIA 实验报告：DHCP 与 Telnet 组网

## 文章导读
本篇是 HCIA 综合实验报告，通过**DHCP 动态分配、手工配置、Telnet 远程登录、域名访问**等配置，实现一个 `192.168.1.0/24` 网段内各终端相互通讯。适合学习华为设备基础网络服务配置的读者。

## 一、实验需求
1. 通过 DHCP 服务，给 PC4 和 PC5 分配 IP 地址、网关、掩码、DNS 服务器 IP 地址
2. Client-1 手工配置 IP 地址为 `192.168.1.1`，可以通过该设备使用域名成功访问 HTTP 服务器
3. Telnet 客户端可以远程登录 Telnet 服务器进行设备管理，并成功修改 Telnet 服务器名称为 `123`；登录账号密码为 `admin/admin`
4. DHCP 服务器需要排除被手工配置的 IP 地址，并修改租期时间为 1 小时
5. 最终实现每台终端都可以相互通讯（ping 成功）
6. 整个拓扑使用 `192.168.1.0/24` 网段进行分配

## 二、实验分析
1. 需对除 PC4 和 PC5 外的终端进行手工配置
2. 需将 `192.168.1.0/24` 划分为两个广播域
3. 保障各个设备之间保持联通

## 三、基础配置

**DHCP Server 接口 IP 配置**
```
[DHCP Server]interface g0/0/0
[DHCP Server-GigabitEthernet0/0/0]ip address 192.168.1.126 25

[DHCP Server]interface g0/0/1
[DHCP Server-GigabitEthernet0/0/1]ip address 192.168.1.254 25
```

## 四、Telnet 服务配置

**Telnet Server 配置**
```
# 配置 IP 地址
[Telnet Server]interface g0/0/0
[Telnet Server-GigabitEthernet0/0/0]ip address 192.168.1.131 25

# 补充设备路由表
[Telnet Server]ip route-static 0.0.0.0 0 192.168.1.254

# 启动 Telnet 协议
[Telnet Server]telnet server enable

# 开启虚拟用户终端接口
[Telnet Server]user-interface vty 0 4

# 设置账号登录模式（账号密码）
[Telnet Server-ui-vty0-4]authentication-mode aaa

# 创建账号密码信息
[Telnet Server]aaa
[Telnet Server-aaa]local-user admin password cipher admin

# 设置账户权限
[Telnet Server-aaa]local-user admin privilege level 15

# 设置账号使用的登录协议
[Telnet Server-aaa]local-user admin service-type telnet
```

**Telnet Client 配置**
```
# 配置客户端 IP 地址
[Telnet Client]interface g0/0/0
[Telnet Client-GigabitEthernet0/0/0]ip address 192.168.1.2 25

# 补充设备路由表
[Telnet Client]ip route-static 0.0.0.0 0 192.168.1.126
```

**测试 Telnet 登录**
```
<Telnet Client>telnet 192.168.1.131      # 登录 IP 为 192.168.1.131 的设备

  Press CTRL_] to quit telnet mode
  Trying 192.168.1.131 ...
  Connected to 192.168.1.131 ...

Login authentication

Username: admin       # 账户
Password: admin       # 密码

<Telnet Server>       # 登录成功
```

> 登录成功后，可将 Telnet 服务器名称修改为 `123`。

## 五、DHCP 服务配置

**启动 DHCP 服务并创建地址池塘**
```
# 启动 DHCP 服务
[DHCP Server]dhcp enable

# 创建左边广播域的 IP 地址池塘
[DHCP Server]ip pool one
[DHCP Server-ip-pool-one]network 192.168.1.0 mask 25     # 将 192.168.1.0/25 网段加入池塘
[DHCP Server-ip-pool-one]gateway-list 192.168.1.126      # 设置网关
[DHCP Server-ip-pool-one]dns-list 192.168.1.129          # 设置 DNS 服务器

# 排除手工配置的 IP 地址，防止冲突
[DHCP Server-ip-pool-one]excluded-ip-address 192.168.1.1 192.168.1.2

# 在接口激活 DHCP 服务
[DHCP Server]interface GigabitEthernet 0/0/0
[DHCP Server-GigabitEthernet0/0/0]dhcp select global

# 修改租期时间为 1 小时
[DHCP Server-ip-pool-one]lease day 0 hour 1 minute 0
```

**创建右边广播域的地址池塘**
```
[DHCP Server]ip pool two
[DHCP Server-ip-pool-two]network 192.168.1.128 mask 25
[DHCP Server-ip-pool-two]gateway-list 192.168.1.254
[DHCP Server-ip-pool-two]dns-list 192.168.1.129
[DHCP Server-ip-pool-two]excluded-ip-address 192.168.1.129 192.168.1.131

[DHCP Server]interface GigabitEthernet 0/0/1
[DHCP Server-GigabitEthernet0/0/1]dhcp select global
```

## 六、实验结果
完成上述配置后，PC4 和 PC5 通过 DHCP 正确获取地址，手工配置的 Client-1 可用域名访问 HTTP 服务器，Telnet 客户端可远程登录并管理设备，各终端 ping 互通，实验成功。
