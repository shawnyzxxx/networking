# OSPF 实验报告

## 文章导读
本篇是 OSPF 多区域组网的实验报告，涵盖**子网划分、DR/BDR 选举、MD5 密文认证、环回接口宣告、多区域 OSPF 配置**，最终实现全网可达。适合学习华为设备 OSPF 组网的读者。

## 一、实验需求
1. 整个网络使用 `192.168.1.0/24` 进行地址分配
2. Area 0 区域中，R1 为 DR，R2 为 BDR
3. R3 与 R4 之间使用密文认证，密码为 `Admin@huawei.com`
4. R1、R2、R5 各配置一个环回接口，R1 和 R2 的环回接口宣告到 OSPF 网络
5. 设备的 RID 为每台设备的名称编号（AR1–1.1.1.1）
6. 全网可达

## 二、实验分析
1. 全网处于同一网段，需要子网划分
2. 选举出 DR 和 BDR
3. R3 与 R4 进行加密时，两端口都要加密
4. 注意验证全网是否相通

## 三、子网划分
将 `192.168.1.0/24` 划分为两段，两个区域各分一段。区域一需要一个主干和两个环回，区域二需要两个主干和一个环回，各需要三个网段，再从每个区域中分出 3 个网段。

| 网段 | 区域 |
|---|---|
| 192.168.1.0/24 | 总段 |
| 192.168.1.0/25 | 区域一 |
| 192.168.1.128/25 | 区域二 |

**区域一**

| 网段 | 用途 |
|---|---|
| 192.168.1.0/25 | 区域一 |
| 192.168.1.0/27 | 主干 |
| 192.168.1.32/27 | R1 环回 |
| 192.168.1.64/27 | R2 环回 |
| 192.168.1.96/27 | 预留 |

**区域二**

| 网段 | 用途 |
|---|---|
| 192.168.1.128/25 | 区域二 |
| 192.168.1.128/27 | 主干 |
| 192.168.1.160/27 | 主干 |
| 192.168.1.192/27 | R5 环回 |
| 192.168.1.224/27 | 预留 |

## 四、实验步骤

### 1. 设备接口与环回配置
```
[r1]interface g0/0/0
[r1-GigabitEthernet0/0/0]ip address 192.168.1.1 27
[r1]interface LoopBack 0
[r1-LoopBack0]ip address 192.168.1.33 27

[r2]interface g0/0/0
[r2-GigabitEthernet0/0/0]ip address 192.168.1.2 27
[r2]interface LoopBack 0
[r2-LoopBack0]ip address 192.168.1.65 27

[r3]interface g0/0/0
[r3-GigabitEthernet0/0/0]ip address 192.168.1.30 27
[r3]interface g0/0/1
[r3-GigabitEthernet0/0/1]ip address 192.168.1.158 27

[r4]interface g0/0/0
[r4-GigabitEthernet0/0/0]ip address 192.168.1.129 27
[r4]interface g0/0/1
[r4-GigabitEthernet0/0/1]ip address 192.168.1.161 27

[r5]interface g0/0/0
[r5-GigabitEthernet0/0/0]ip address 192.168.1.190 27
[r5]int LoopBack 0
[r5-LoopBack0]ip address 192.168.1.193 27
```

### 2. DR 和 BDR 选举
```
[r1-GigabitEthernet0/0/0]ospf dr-priority 6     # DR
[r2-GigabitEthernet0/0/0]ospf dr-priority 5     # BDR
```

### 3. R3 和 R4 通过密文认证（MD5）加密
```
[r3]interface g0/0/1
[r3-GigabitEthernet0/0/1]ospf authentication-mode md5 1 cipher Admin@huawei.com
[r4]interface g0/0/0
[r4-GigabitEthernet0/0/0]ospf authentication-mode md5 1 cipher Admin@huawei.com
```

### 4. 启用 OSPF 协议
```
[r1]ospf 1 router-id 1.1.1.1
[r1-ospf-1]area 0
[r1-ospf-1-area-0.0.0.0]network 192.168.1.1 0.0.0.0
[r1-ospf-1-area-0.0.0.0]network 192.168.1.33 0.0.0.0

[r2]ospf 1 router-id 2.2.2.2
[r2-ospf-1]area 0
[r2-ospf-1-area-0.0.0.0]network 192.168.1.2 0.0.0.0
[r2-ospf-1-area-0.0.0.0]network 192.168.1.65 0.0.0.0

[r3]ospf 1 router-id 3.3.3.3
[r3-ospf-1]area 0
[r3-ospf-1-area-0.0.0.0]network 192.168.1.30 0.0.0.0
[r3-ospf-1]area 1
[r3-ospf-1-area-0.0.0.1]network 192.168.1.158 0.0.0.0

[r4]ospf 1 router-id 4.4.4.4
[r4-ospf-1]area 1
[r4-ospf-1-area-0.0.0.1]network 192.168.1.129 0.0.0.0
[r4-ospf-1-area-0.0.0.1]network 192.168.1.161 0.0.0.0

[r5]ospf 1 router-id 5.5.5.5
[r5-ospf-1]area 1
[r5-ospf-1-area-0.0.0.1]network 192.168.1.190 0.0.0.0
[r5-ospf-1]default-route-advertise always
```

## 五、实验检验
查看邻居简表（以 R3 为例），并通过 `ping` 指令进行全网连通性测试。

## 六、实验结果
实验成功，全网可达。
